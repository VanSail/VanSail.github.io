# Doc Cards

Place `<DocCardList />` on a category's home page to automatically list all doc cards in that directory; no manual link maintenance needed.

## Usage

<Tabs>
<TabItem value="use" label="Source" default>

````md
<DocCardList />
````

</TabItem>
<TabItem value="effect" label="Result">

<DocCardList />

</TabItem>
</Tabs>

> Cards automatically aggregate all tutorials in this section.
