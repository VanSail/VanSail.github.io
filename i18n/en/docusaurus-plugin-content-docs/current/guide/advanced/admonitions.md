# Admonitions

Wrap content with `:::type`; add a title with `:::type[title]`.

## Note

<Tabs>
<TabItem value="use" label="Source" default>

```text
::::note
Note
:::: 
```

</TabItem>
<TabItem value="effect" label="Result">

::::note[Note]
Note
::::

</TabItem>
</Tabs>

<Tabs>
<TabItem value="use" label="Source" default>

```text
::::note[Note Title]
This is titled note content.
::::
```

</TabItem>
<TabItem value="effect" label="Result">

::::note[Note Title]
This is titled note content.
::::

</TabItem>
</Tabs>
