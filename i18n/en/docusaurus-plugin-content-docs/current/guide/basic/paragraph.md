# Paragraphs

## Blockquotes

Write multiple lines for one quote (each line starts with `>`); a blank line in between splits it into **two separate blockquotes**.

<Tabs>
<TabItem value="use" label="Source" default>

````md
> First quote

> Second quote
````

</TabItem>
<TabItem value="effect" label="Result">

> First quote

> Second quote

</TabItem>
</Tabs>

## Horizontal Rule

<Tabs>
<TabItem value="use" label="Source" default>

````md
Previous paragraph

---

Next paragraph
````

</TabItem>
<TabItem value="effect" label="Result">

Previous paragraph

---

Next paragraph

</TabItem>
</Tabs>
