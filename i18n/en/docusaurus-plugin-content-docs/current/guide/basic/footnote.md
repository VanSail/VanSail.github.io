# Footnotes

Reference in the body with `[^tag]`, then define it at the end with `[^tag]: content`; the tag must match on both sides.

<Tabs>
<TabItem value="use" label="Source" default>

````md
Body text with a note[^1].

[^1]: Footnote content.
````

</TabItem>
<TabItem value="effect" label="Result">

Body text with a note[^1].

[^1]: Footnote content.

</TabItem>
</Tabs>
