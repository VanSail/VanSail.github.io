# 段落

## 引用

同一段引用可写多行（每行以 `>` 开头）；若要用空行隔开，则会拆成**两个独立的引用块**。

<Tabs>
<TabItem value="use" label="实现代码" default>

````md
> 第一段引用

> 第二段引用
````

</TabItem>
<TabItem value="effect" label="实际效果">

> 第一段引用

> 第二段引用

</TabItem>
</Tabs>
