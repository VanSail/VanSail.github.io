# Conda 使用

Conda 是跨平台的**包、依赖与环境管理器**，最广为人知的两发行版是 **Anaconda**（开箱即用的完整科学计算套件）与 **Miniconda**（仅含 Conda 本身的极简版本）。它既能管理 Python 包，也能管理 C/C++ 等非 Python 依赖，是数据科学、机器学习与嵌入式 AI 开发的常用工具。

本栏目按「基础 → 命令 → 速查」组织：先建立概念并安装 Anaconda / Miniconda，再系统学习环境与包管理命令，最后用速查表随时翻阅。
